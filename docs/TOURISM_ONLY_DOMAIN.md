# Tourism and Hospitality Only

This TravelMind distribution is configured for one sector: **Tourism and Hospitality**.

Supported project types include:

- Hotel, resort, hostel, lodge, homestay, and accommodation systems
- Guest booking, check-in, check-out, guest profiles, and guest-service systems
- Housekeeping, maintenance, front-desk, concierge, and incident-management systems
- Tour, activity, attraction, event, restaurant, and destination-service platforms
- Tourism partner, channel, property-management, transport, and supplier integrations
- Tourism safety, accessibility, privacy, sustainability, and visitor-experience systems

The RAG index contains only Tourism and Hospitality documents plus three necessary cross-cutting topics: SDLC selection, cybersecurity, and AI application security. Finance, banking, lending, investment, healthcare, aerospace, and unrelated sector sources are intentionally excluded.

If a user submits a non-tourism request, the assistant should explain that the configured domain is Tourism and Hospitality and ask for a tourism/hospitality version of the scenario rather than switching sectors.
